# Transition Language

## Dimensional Gateways
- Moving between sections is a "Dimensional Morph", not a navigation change.
- **Rules**:
  - `Morphing`: Geometry from the previous dimension should "shatter" or "dissolve" into the next.
  - `Atmospheric Sync`: The global pulse should ramp up/down during the transition.
  - `Sound (Planned)`: Audio signatures shift from chaotic to deep to precise.

## Interaction Transitions
- Opening a knowledge object should feel like "entering" its context within the current space.
