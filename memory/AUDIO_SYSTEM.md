# Audio System

## Philosophy
Restrained atmospheric audio that reinforces the semi-physical nature of the ecosystem.

## Components
- **Ambient Hum**: Low-frequency background pulse that shifts frequency based on dimension.
- **Tactile Feedback**: Subtle 'blips' and 'thuds' for UI interaction (hover/click).
- **Systemic Alerts**: Dissonant tones during Anomaly events or security breaches.
- **Success Cues**: Harmonic resolution on registry persistence.
