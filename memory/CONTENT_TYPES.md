# CONTENT TYPES — NEXUS VEIL

## Core Principle

Knowledge Objects are NOT:
simple cards or posts.

They are:
reactive ecosystem entities.

Each object:
- affects world-state
- may influence dimensions
- may propagate anomalies
- may create relationships
- participates in the living ecosystem

---

# 1. Repository

## Purpose

Represents:
a GitHub repository,
framework,
tool,
or engineering system.

---

## Required Fields

- title
- repository URL
- short description
- ecosystem purpose
- tags
- dimension assignment

---

## Optional Fields

- preview image
- influence strength
- signal classification
- relationships
- danger level

---

## Creator Note

The creator should explain:
WHY this repository matters.

Not only:
what it is.

---

# 2. Threat Feed

## Purpose

- threat monitoring

## Behavior

Threat feeds may:
- increase tension

- affect ecosystem stability
