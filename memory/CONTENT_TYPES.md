# Content Types

## Entity Categories

### 1. Knowledge Object (The Signal)
- **Base**: ID, Label, Value, Status.
- **Affinity**: The dimension where the object resides.
- **Influence**: How it mutates Tension, Entropy, and Anomaly.

### 2. Neural Link (The Connection)
- **Types**: Resonance, Corruption, Dependency, Monitoring, Interference.
- **Function**: Propagates atmospheric shifts between linked objects.

### 3. Environmental Cluster (The Scene)
- **Function**: Groups objects to create a unified systemic sub-state.
- **Modifiers**: Persistent shifts to Tension/Entropy/Anomaly.
