# Interaction Rules

## General
- Interface reacts to global state: Time, Weather, Pulse.
- Exploration is rewarded; secrets are discoverable.
- Desktop-first, experience-first.

## Cybersecurity
- High-tension feedback.
- Glitch-reactive to user input.
- Aggressive warnings and state changes.

## OSINT
- Layered exploration (parallax, zooming).
- Discovery-based interaction (hovering reveals hidden nodes).
- Investigative feel (tracing connections).

## GitHub
- High precision.
- Sharp, clean feedback.
- Logical and structured response to interaction.
- Stability-oriented (less noise, more signal).
