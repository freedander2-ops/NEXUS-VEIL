# Onboarding & Guidance

## Philosophy
No operator should ever feel lost. The system must explain its own complexity semantically.

## Guided Flow
1. **Initial Protocol**: Explaining the authentication and role selection.
2. **Environmental Briefing**: Introducing the four primary dimensions.
3. **Manipulation Training**: How to use the Injection Protocol and Neural Mapping.
4. **Stability Protocol**: Understanding the "Live Diagnostics" and world-state safety rails.

## Empty States
- Each dimension should provide guidance if no objects are present.
- The Operator Workspace should use empty states to suggest the next logical action.
