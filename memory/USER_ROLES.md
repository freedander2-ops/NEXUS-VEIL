# USER ROLES — NEXUS VEIL

## Core Principle

NEXUS VEIL is NOT:
a public editing platform.

It is:
a personal ecosystem infrastructure
with controlled operator access.

---

# 1. Guest

## Purpose

Guests may:
- explore dimensions
- observe atmosphere
- interact with public systems
- discover anomalies
- experience ecosystem reactions

---

## Restrictions

Guests may NOT:
- edit objects
- modify relationships
- inject content
- alter scenes
- access operator systems

---

## Atmosphere

Guest experience should feel:
mysterious,
immersive,
and exploratory.

---

# 2. Operator (Admin)

## Purpose

The operator controls:
- content injection
- ecosystem structure
- relationships
- world-state tuning
- environmental behavior

---

## Operator Access

Operator access requires:
authentication.

Recommended routes:
- /gateway
- /operator

Avoid:
direct public operator exposure.

---

## Operator Philosophy

The operator interface is NOT:
a traditional admin panel.

It should feel:
like controlling
a living ecosystem.

---

# 3. Authentication Behavior

The system should support:
- persistent sessions
- secure logout
- session reset
- operator-only routes

---

## Login Flow

Recommended flow:

/gateway
→ credential input
→ role detection
→ ecosystem routing

---

## Example

guest
→ public ecosystem

admin
→ operator workspace

---

# 4. Privacy Acknowledgment

Before entering:
users should acknowledge:
- atmospheric data usage
- local environmental adaptation
- ecosystem interaction logging

The project should remain:
transparent and legally safe.

---

# 5. Creator Isolation

Only operators may:
- modify ecosystem structure
- inject runtime objects
- create relationships
- manipulate scenes

The ecosystem is:
centrally curated.

---

# 6. Future Expansion

Possible future roles:
- observer
- analyst
- restricted operator

But:
the current system should remain:
simple and stable.

---

# 7. Security Philosophy

Security should prioritize:
- simplicity
- stability
- controlled access
- minimal attack surface

Avoid:
overengineered authentication systems.
