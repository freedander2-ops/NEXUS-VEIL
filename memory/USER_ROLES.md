# User Roles

## 1. Guest (Observer)
- **Access**: Read-only access to public dimensions.
- **Experience**: Atmospheric immersion, exploration, and observation.
- **Gate**: Symbolic login (guest/guest).

## 2. Operator (Creator)
- **Access**: Full ecosystem manipulation capabilities.
- **Experience**: Technical intervention, entity injection, and atmospheric tuning.
- **Workspace**: /operator
- **Gate**: Symbolic login (admin/admin).
