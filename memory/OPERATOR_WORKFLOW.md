# Operator Workflow

## Basic Flow

1. Login
2. Open Operator Workspace
3. Create or edit object
4. Assign dimension
5. Configure influence
6. Preview ecosystem reaction
7. Save
8. Observe propagation

---

## Creator Goals

The operator workflow must feel:
- fast
- understandable
- stable
- atmospheric
- non-technical

The creator should not feel:
like they are editing backend infrastructure.
