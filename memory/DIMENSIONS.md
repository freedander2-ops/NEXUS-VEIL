# Dimensions

## Overview
NEXUS VEIL is divided into distinct environmental dimensions, each with its own visual language, motion profile, and systemic purpose.

## Dimension Registry

### 1. Digital Weather (Atmospheric Core)
- **Purpose**: Global synchronization and mood monitoring.
- **Visuals**: Particles, fog, and light intensity driven by planetary data.
- **Operator Role**: Balance the global pulse.

### 2. Cybersecurity (Tactical Threat Space)
- **Purpose**: Real-time intrusion detection and anomaly visualization.
- **Visuals**: Unstable grids, aggressive jitter, red-spectrum dominance.
- **Behavior**: High-frequency reactions to world-state tension.

### 3. GitHub Signals (Technical Infrastructure)
- **Purpose**: Monitoring code evolution and repository health.
- **Visuals**: Precise geometric structures, rhythmic pulses, blueprint aesthetics.
- **Behavior**: Clean, mathematically satisfying transitions.

### 4. OSINT Layer (Investigation Surface)
- **Purpose**: Geographical node mapping and entity relationship discovery.
- **Visuals**: Drifting parallax, layered map data, deep blue/cyan spectrum.
- **Behavior**: Low-frequency flow and discovery-based interaction.
