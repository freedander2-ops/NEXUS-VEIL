# Environment Rules

## Dimensional Structuralism
- Every dimension has a unique structural logic and pacing.
- **NEVER** reuse layouts, navigation patterns, or spacing systems between dimensions.
- The interface must transform from a "machine" (Cyber) to a "landscape" (OSINT) to a "constellation" (GitHub).

## Continuous Response
- Every user action (even moving the mouse) must create an environmental reaction.
- Interaction weight: elements react to focus and movement speed with inertia.

## Creator Scalability
- Systems must be modular to support runtime shader, atmosphere, and motion tuning.
- Dimensions can "mutate" or "bleed" into one another during anomaly events.
