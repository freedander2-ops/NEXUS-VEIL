# Environment Rules

## The "Dimension" Philosophy
- Every environment is a unique digital reality, not just a themed page.
- Environments MUST NOT share structural DNA (layouts, spacing, nav patterns).
- When a user enters an environment, the entire structural logic of the interface must shift.

## Cybersecurity Dimension
- **Logic**: Unstable, tactical, reactive.
- **Behavior**: The UI itself should feel like it's under pressure. Elements may shift, glitch, or overlap aggressively.
- **Depth**: Tactical layers that appear and disappear based on "threat" signals.

## OSINT Dimension
- **Logic**: Investigative, deep, layered.
- **Behavior**: Information is discovered, not presented. Navigating is like diving through data strata.
- **Depth**: High use of parallax and node-space exploration.

## GitHub Signals Dimension
- **Logic**: Engineered, intelligent, structured.
- **Behavior**: High precision and mathematical elegance. Precise rhythms and efficient motion.
- **Depth**: Clean holographic structures and intelligent dependency constellations.

## Runtime Modification
- Every environment must be defined by a set of parameters that can be altered at runtime (Creator System).
- Rules for "Mutation": Environments can evolve or mutate based on global world states.
