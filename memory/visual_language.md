# Visual Language

## Palette
- **Cybersecurity**: Deep blacks, aggressive reds, emergency oranges.
- **OSINT**: Deep ocean blues, cyan highlights, data-grey.
- **GitHub**: Cold whites, graphite, steel, minimal cyan accents.

## Geometry
- **Cybersecurity**: Broken grids, overlapping windows, glitch artifacts.
- **OSINT**: Geospatial planes, interconnected node clusters, parallax depth.
- **GitHub**: Structured lattices, procedural graph structures, intelligent diagrams.

## Typography
- High-density monospace for technical data.
- Wide tracking for environmental labels.
- Minimalist but sharp UI elements.
