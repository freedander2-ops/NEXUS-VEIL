# Motion Rules

## Frequency
- **Cybersecurity**: High (glitchy, rapid pulses).
- **OSINT**: Medium (scanning, expanding, floating).
- **GitHub**: Low/Intentional (steady pulses, mathematical rotations).

## Character
- **Cybersecurity**: Violent, unpredictable.
- **OSINT**: Probing, investigative.
- **GitHub**: Efficient, graceful, rhythmic.

## Animation
- Framer Motion for UI transitions.
- Three.js for environmental rendering and background layers.
- Seamless "Pulse" state synchronization.
