# World States

## Global Ecosystem Pulses
- **Moods**: `calm`, `alert`, `critical`, `anomaly`.
- **Intensity**: 0.0 to 1.0 (affects all motion and shader frequency).
- **Time/Weather**: External signals that "bleed" into every dimension.

## Environmental Continuity
- The environment remembers anomalies and user interactions to create a persistent "living" habitat.
- Rare events (mutations) that alter the behavior of all sections simultaneously.

---

# World-State Engine

The ecosystem operates using a shared global world-state.

All environments react to:
- tension
- entropy
- corruption
- synchronization
- anomaly level
- signal noise
- stability

---

# Core States

## Calm

Low movement.
Stable environments.
Soft atmospheric motion.

---

## Alert

Increased activity.
Higher motion intensity.
Environmental instability begins to appear.

---

## Critical

Aggressive atmosphere.
Heavy distortion.
High anomaly propagation.
Unstable environmental reactions.

---

## Anomaly

Rare systemic state.

Effects may include:
- environmental corruption
- cross-dimension mutation
- visual instability
- atmosphere desynchronization
- signal interference

Anomalies should remain:
rare and meaningful.

---

# Intensity System

Intensity ranges from:
0.0 → 1.0

Intensity affects:
- motion frequency
- shader behavior
- environmental aggression
- particle activity
- interaction feedback
- mutation probability

---

# Environmental Continuity

The ecosystem should remember:
- anomalies
- interactions
- scene mutations
- signal events
- environmental corruption

The world should feel:
persistent and evolving.

---

# Event Propagation

Events should spread through the ecosystem.

Example:
- OSINT instability increases entropy
- entropy destabilizes GitHub geometry
- corruption affects atmospheric systems
- environments begin mutating together

---

# Environmental Memory

World-state memory should remain lightweight.

The goal is:
persistent atmosphere,
not heavy infrastructure.

---

# Mutation Events

Rare events may alter:
- all environments simultaneously
- motion behavior
- rendering logic
- environmental stability
- anomaly intensity

Mutations should feel:
systemic,
not scripted.

---

# External Signals

The ecosystem may eventually react to:
- real weather
- time of day
- cybersecurity feeds
- global internet tension
- external signals

External systems should influence atmosphere subtly.

Avoid:
information overload.

---

# Long-Term Goal

The world-state system should evolve into:
a living environmental intelligence layer.

The ecosystem should behave like:
an interconnected organism,
not isolated UI sections.
