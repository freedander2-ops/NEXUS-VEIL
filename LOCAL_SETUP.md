# Локальный запуск и модификация NEXUS VEIL

Этот документ поможет вам запустить проект на Windows 10 и понять, как его можно модифицировать.

## 1. Требования

Для запуска проекта на вашем компьютере должны быть установлены:
- **Node.js** (версия 18.x или выше). Скачать можно с [nodejs.org](https://nodejs.org/).
- **npm** (устанавливается вместе с Node.js).
- **Git** (необязательно, но рекомендуется).

## 2. Пошаговая установка

1. **Скачайте код**: Если у вас есть Git, выполните `git clone [url]`. Если нет — просто распакуйте архив с проектом в удобную папку.
2. **Откройте терминал**: Нажмите `Win + R`, введите `cmd` и нажмите Enter. Или используйте PowerShell.
3. **Перейдите в папку проекта**:
   ```cmd
   cd путь/к/папке/nexus-veil
   ```
4. **Установите зависимости**:
   ```cmd
   npm install
   ```
5. **Запустите сервер разработки**:
   ```cmd
   npm run dev
   ```
6. **Откройте браузер**: Перейдите по адресу [http://localhost:3000](http://localhost:3000).

---

## 3. Как модифицировать проект

NEXUS VEIL построен на модульной архитектуре, что позволяет легко менять его атмосферу.

### Изменение цветов и темы
Все основные цвета и эффекты (сканирующие линии, шум) настроены в файле:
- `src/app/globals.css`
Измените переменные в секции `:root` (например, `--cyber-blue`), чтобы мгновенно обновить палитру всего интерфейса.

### Настройка логики окружения (Mood Engine)
Если вы хотите изменить то, как интерфейс реагирует на события, загляните в:
- `src/lib/environment/moodLogic.ts`
Здесь можно настроить цвета акцентов, частоту глитчей (помех) и плотность частиц для каждого состояния (`calm`, `tense`, `alert`, `critical`).

### Редактирование 3D фона
Фон на Three.js находится здесь:
- `src/components/environment/BackgroundCanvas.tsx`
Вы можете изменить геометрию частиц, их скорость вращения или добавить новые 3D объекты.

### Текст терминала и логика входа
Для изменения последовательности загрузки или логики аутентификации:
- `src/components/auth/LoginTerminal.tsx`
Вы можете добавить свои собственные строки в массив `fullBootSequence`.

## 4. Возможные модификации для будущего
1. **Интеграция реальной погоды**: В `src/lib/environment/state.tsx` можно добавить fetch-запрос к Weather API, чтобы проект реально реагировал на дождь за вашим окном.
2. **Секретные маршруты**: Добавьте новые файлы в `src/app/`, например `src/app/secret/page.tsx`, и сделайте переход на них по скрытой команде в терминале.
3. **Звуковое сопровождение**: Добавьте фоновый эмбиент, который меняет громкость или фильтры в зависимости от `intensity` из нашего Environment Engine.
