# Visual Identity Memory

## Core Color Palette
- **Cyber Blue**: #3b82f6 (Main interaction)
- **Cyber Cyan**: #06b6d4 (Secondary highlights)
- **Cyber Red**: #ef4444 (Alerts, Cyber section dominant)
- **Cyber Black**: #020202 (Background depth)
- **Cyber Dark**: #0a0a0a (UI panels)

## Typography
- **Headings**: Uppercase, high tracking (0.3em+), bold.
- **Data**: Monospace (Geist Mono), lowercase for secondary metadata.
- **Labels**: 10px uppercase tracking-widest.

## Materiality
- CRT scanlines and subtle noise.
- Translucent backgrounds (backdrop-blur-xl).
- Thin borders (border-cyber-blue/10).
