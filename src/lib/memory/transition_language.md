# Transition Language

## Dimensional Morphing
- Transitions between sections must not be simple fades.
- **Cyber Entry**: Causes screen shake and chromatic aberration.
- **OSINT Entry**: Slows motion and expands FOV.
- **GitHub Entry**: Increases UI sharpness and clears atmospheric noise.

## Global State Triggers
- Atmospheric changes must propagate from the `EnvironmentProvider` to all active Three.js components.
