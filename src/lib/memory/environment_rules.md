# Environment Rules

## Mood States
1. **Calm**: Minimal movement, blue/cyan accents, slow particle drift.
2. **Tense**: Increased rotation speed, yellow/cyan accents.
3. **Alert**: High particle density, green accents, rhythmic pulse.
4. **Critical**: Glitch frequency high, red accents, environmental flashes.

## Intensity Scaling
- All animations (rotation, pulse, glitch) must scale with `intensity` parameter (0.0 to 1.0).

## Anomaly Logic
- Random glitches triggered based on intensity.
- Secret routes accessible via specific symbolic credentials.
